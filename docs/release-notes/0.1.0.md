# Steppe 0.1.0

First public build of Steppe, a Ghostty fork with a native Herdr cockpit.

## Highlights

- Native sidebar with workspaces, agents, live status, and click-to-focus.
- Per-pane `pane.agent_status_changed` subscriptions and authoritative snapshot refresh.
- Native notifications and dock badge for blocked/done agents.
- Named-session picker, new workspace/tab, split right/down, and focus-next-attention actions.
- “Open Herdr in New Tab” from the Steppe menu or sidebar.
- Rebranded app bundle (`Steppe.app`, `dev.steppe.app`, Steppe icon).
- Reconnect with backoff, `events_lost` recovery, wake/activate refresh.

## Install

This release is **ad-hoc signed**, not notarized. macOS Gatekeeper may warn on first launch;
use right-click → Open, or build from source.

```sh
open Steppe.app
```

Requires a running Herdr server. Start one with `herdr attach`.

## Known limitations

- Not signed or notarized with a Developer ID.
- Notification authorization may be refused for an ad-hoc build; use System Settings or a
  signed build.
- Steppe reads Ghostty's config at `~/.config/ghostty/config`.
- The sidebar is fixed-width and has no settings pane yet.
