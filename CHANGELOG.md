# Changelog

## 0.1.0

First local release of Steppe, a Ghostty fork with a native Herdr cockpit.

- Native macOS sidebar with workspaces, agents, live status, and click-to-focus.
- Per-pane agent status subscriptions with authoritative snapshot reconciliation.
- Native notifications and dock badge for blocked/done agents.
- Named-session picker that swaps the Herdr store without restarting the app.
- Sidebar actions: new workspace, new tab, split right/down, focus next attention.
- "Open Herdr in New Tab" from the Steppe menu or sidebar.
- `steppe-sidebar` Ghostty config key, sidebar visibility persisted per user.
- Rebranded app bundle (`Steppe.app`, `dev.steppe.app`, Steppe icon).
- Build and packaging scripts; ReleaseLocal DMG/ZIP artifacts.
